================================================================
⚠️ 占位音频 — 必须用真实音频替换
================================================================
当前文件 `久别04_成品.wav` 和 `久别04_成品.mp3` 是用 Python 标准库
生成的 30 秒 22050Hz 占位正弦波（A4-C5-E5 三音循环，0 音量级）。

**这是为了填目录结构而自动生成的占位，不是真实作品音频。**

请按以下步骤替换为真实音频：

步骤 1：从本工具获取提示词包
  - 启动古韵AI 后端 (uvicorn app.main:app)
  - 启动前端 (npm run dev) 或 Electron 桌面 (npm start)
  - 在 Step 3 页面点击「🚀 立即在 MiniMax 中创作」
  - 该按钮会自动复制 Meta + Styles + Lyrics 到剪贴板，
    并在默认浏览器打开 https://minimaxi.com/audio/music

步骤 2：在 MiniMax Audio 网页版粘贴并生成
  - 登录 MiniMax 账号
  - 选择模型：Music-3.0
  - 粘贴 Styles 到「风格描述」框
  - 粘贴歌词到「歌词」框（纯音乐模式则留空 + 勾选 Instrumental）
  - 设置时长 3.5-4.5 分钟
  - 点击「生成」，试听候选，下载满意版本

步骤 3：替换本目录占位文件
  - 将下载的 mp3 重命名为 `久别04_成品.mp3` 覆盖此占位
  - 如有 WAV（48kHz/24bit），也命名为 `久别04_成品.wav` 覆盖此占位
  - 推送替换后的文件到 GitHub:
    ```
    git add AI音乐赛道提交包/01_作品文件/
    git commit -m "替换占位音频为真实成品"
    git push
    ```

================================================================
替代方案（可选）
================================================================
如果无法访问 MiniMax 网页版，可以：
1. 使用 Suno (https://suno.com) / Udio (https://udio.com)
   等其他支持自定义歌词与风格描述的 AI 音乐平台
2. 使用任何商用音乐制作软件手工制作
3. 联系参赛团队成员手工演唱/演奏

无论哪种方案，最终成品必须是 30 秒以上的完整音乐片段，且
歌词部分应与本工具生成的 Lyrics 一致。
